Como preencher os Botões

Visitar Website

Abre um URL no browser do utilizador. Preenches:

  • Texto do Botão — o que aparece no botão (ex: "Ver proposta")
  • URL — o endereço para onde abre (ex: https://fuetmagico.pt/proposta/123)
  • URL Type Estático — URL fixo, igual para todos os envios
  • URL Type Dinâmico — URL com {{1}} no final que é preenchido no momento do envio

Ligar para Número

Inicia uma chamada telefónica ao clicar. Preenches:

  • Texto do Botão — o que aparece no botão (ex: "Falar connosco")
  • Número — com indicativo do país (ex: +351 210 000 000). Tem de ser fixo por template.

A Meta permite no máximo 2 botões por template. Não é possível misturar tipos diferentes no mesmo template.

Como preencher as Variáveis

No corpo da mensagem usas {{1}}, {{2}}… para marcar onde vão os dados dinâmicos. Aqui defines de onde vem cada um.

Colunas

  • Var. — o número que corresponde ao {{N}} no corpo
  • Campo — o caminho do campo no registo (ex: contact.name vai buscar o nome do contacto associado)
  • Fallback — valor usado se o campo estiver vazio no registo (ex: "Cliente")

Exemplo

Corpo: Olá {{1}}, a sua proposta {{2}} foi aprovada.

• {{1}} → Campo: contact.name | Fallback: Cliente

• {{2}} → Campo: title | Fallback: a sua proposta

Usa o campo Modelo de Referência acima para ativar o autocomplete dos campos disponíveis.
