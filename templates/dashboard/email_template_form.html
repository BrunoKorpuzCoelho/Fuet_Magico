Var Campo Fallback Variável

Usa {{1}}, {{2}}... ou a variável completa {{ lead.title }} no corpo do email. No envio, são substituídas pelo valor real. Se o campo estiver vazio, é usado o fallback.

Como Usar Variáveis

1. Escolhe o Módulo no formulário (CRM, Contactos, etc.) para definir os campos disponíveis.

2. Clica em + Adicionar linha e escolhe um campo no dropdown (ex: lead.title).

3. Define um Fallback — valor usado se o campo estiver vazio na BD.

4. No corpo do email, usa a variável de duas formas:

  • Variável curta: {{1}} — rápida, numérica
  • Variável completa: {{ lead.title }} — descritiva

Os números nunca são renumerados. Se apagares a variável 3, a próxima será a 4 na mesma.
